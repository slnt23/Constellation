# Kite 剩余兼容迁移计划

状态：**已完成**。旧按层目录已全部移除，项目已切换到 Hybrid（Feature-first）架构。

## 最终架构

```text
src/
├── app/                # 应用入口与 providers 初始化
├── core/               # 框架层：api / router / permission / config
├── shared/             # 共享组件、常量、类型、样式、资源
├── modules/            # 业务模块：home / blog / user / ai / price / admin / story / meditation
├── layouts/            # 门户布局
└── main.ts             # 已迁移至 src/app/main.ts
```

## M1：登录接口迁入 User 模块 ✅

- `src/api/modules/auth.api.ts` → `src/modules/user/api/auth.ts`
- 认证 DTO 迁入 `src/modules/user/types/auth.ts`
- `core/permission/auth.ts`、`LoginDialog`、`ProfileAccountSection` 已改从 `modules/user` 导入

## M2：共享类型迁入 `shared/types` ✅

- `Result`、`PageResult` 等统一返回类型迁入 `src/shared/types/result.ts`
- 公共 UI 类型迁入 `src/shared/types/common.ts`
- 前台/模块类型迁入 `src/shared/types/front.ts`
- 用户身份与地址类型迁入 `src/shared/types/user.ts`
- 已删除 `src/types/`

## M3：Pitaya 已取消开发 ✅

- Pitaya 电商中心已取消开发，`src/modules/pitaya/` 已删除
- `.docs/frontend-api.md` 中电商中心章节标记为已取消

## M4：共享资源统一到 `shared/` ✅

- `src/constant/modules/key.constant.ts` → `src/shared/constants/key.ts`
- `src/style/` → `src/shared/styles/`
- `src/assets/` → `src/shared/assets/`
- 所有 `@/assets/*`、`/src/assets/*` 路径已同步更新

## M5：应用启动迁入 `src/app/` ✅

- `src/main.ts`、`src/App.vue` → `src/app/`
- 新增 `src/app/providers/` 承载 Pinia、Router、Element Plus、ECharts 初始化
- `index.html` 入口已更新

## M6：删除旧目录并收尾 ✅

- 已删除 `src/api/`、`src/constant/`、`src/types/`、`src/views/`、`src/components/`、`src/config/`、`src/router/`、`src/stores/`、`src/composables/`、`src/utils/`
- 已完成 `npm run type-check` 与 `npm run build` 验证

## 完成标准

- `src` 顶层只保留：`app/`、`core/`、`shared/`、`modules/`、`layouts/`
- 不存在旧按层目录和兼容 shim
- 登录接口与认证 DTO 全部位于 `src/modules/user/`
- 所有业务模块遵循 Feature-first 结构
