# Kite Studio — 个人网站操作系统

基于 **Vue 3 + TypeScript** 的全栈个人品牌平台，采用前后台双门户架构与模块注册式扩展系统，融合 AI 对话、数据可视化、滚动驱动动画等能力。

---

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 框架 | Vue 3.5 + TypeScript 6 | Composition API，全量类型覆盖 |
| 构建 | Vite 7 | unplugin 自动导入 Element Plus，/api 开发代理 |
| 路由 | Vue Router 5 | 双路由表（前台 + 后台），三级路由守卫 |
| 状态管理 | Pinia 3 | 已集成，与 localStorage CustomEvent 混合方案 |
| UI 组件库 | Element Plus 2.13 | 全局主题覆盖，按需自动注册 |
| 数据可视化 | ECharts 6 + vue-echarts 8 | 仪表盘 / 折线图 / 条形图 / 雷达图 |
| HTTP 客户端 | Axios 1.15 | 统一实例，JWT Bearer 拦截器，Result\<T\> 解包 |
| 样式方案 | Sass (SCSS) | CSS 自定义属性设计系统，10 级响应式断点 |
| 认证 | JWT (localStorage) | CustomEvent 跨组件同步，Bearer 令牌注入 |

## 实现功能

### 前台门户（7 个页面）

- **首页** — 全屏视频 Hero + 滚动驱动 3D 卡片翻转动画 + IntersectionObserver 数字滚动 + Spotlight 精选网格 + CTA 行动区
- **AI 对话** — 多会话管理、流式消息渲染、输入中动画指示器、模拟回复引擎（后端接口已就位）
- **价格行情** — 四种数据视图（最新报价 / 趋势折线图 / 地区对比条形图 / 来源雷达图），ECharts 交互式仪表盘
- **作品画廊** — 12 件作品网格 + 全屏灯箱（Teleport 渲染、键盘导航）
- **个人博客** — 文章列表、技能标签云、教育时间线
- **个人中心** — GitHub 风格设置侧边栏，5 个配置分区（公开资料 / 账户 / 外观 / 无障碍 / 通知）
- **自适应导航** — 头部按滚动方向显隐，Shift+Q 快捷键呼出全屏菜单面板

### 后台门户

- **仪表盘** — 管理控制台入口，Spotlight / Feature 内容 CRUD

### 基础设施

- **Axios 封装** — 统一实例（10s 超时）+ 请求拦截器自动注入 Bearer 令牌 + 响应拦截器统一解包 Result\<T\>
- **认证系统** — 邮箱验证码 / 密码双模式登录 + 注册，localStorage 持久化 + CustomEvent 跨标签页同步
- **模块注册系统** — 将功能模块抽象为可插拔单元（key / portal / status / group），按前台-后台和构建状态分组管理
- **设计系统** — 66+ CSS 自定义属性，双变量体系（自定义 + Vercel 风格），Element Plus 全量主题覆盖
- **路由守卫** — 三级权限控制（公开 / 需认证 / 仅管理员），未登录拦截与重定向

## 架构亮点

### 模块注册式扩展

将每个功能定义为注册模块（含状态、所属门户、分组），通过配置中心集中管理，而非散落在路由表中。现有 6 个模块覆盖品牌展示、内容管理和后台运营，新增模块仅需 4 步。

### 滚动驱动 3D 卡片

FeatureGrid 组件使用 `requestAnimationFrame` + IntersectionObserver 实现滚动驱动的透视变换：卡片从堆叠状态平滑过渡到展开状态，伴随 3D 翻转、位移和缩放效果，无需引入动画库。

### 双变量设计系统

同时维护自定义设计变量与 Vercel 风格设计变量两套体系，实现视觉主题化和品牌一致性。CSS 自定义属性涵盖颜色、圆角、阴影、间距和排版全维度。

### 无 Pinia 的轻量认证

利用 `localStorage` + `CustomEvent` 实现令牌管理与跨组件状态同步，不依赖中央状态库即可完成登录态广播和用户信息共享，适用于前期快速迭代阶段。

### ECharts 6 交互式仪表盘

价格行情模块集成 4 种图表类型：可信度饼图 + 可靠性刻度环、可缩放时间序列折线图（含均线、极值标记）、按可信度着色的水平条形图、多轴雷达图 —— 均配备交互工具箱（保存图片、数据缩放）。
