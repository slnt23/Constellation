# Kite Studio

基于 Vue 3 + TypeScript 的个人网站平台，前后台双门户架构。

## 技术栈

Vue 3 · TypeScript · Vite · Vue Router · Pinia · Element Plus · Axios · ECharts · Sass

## 快速开始

```bash
npm install
npm run dev      # 开发服务器 (http://localhost:5173)
npm run build    # 生产构建
npm run preview  # 预览生产构建
```
